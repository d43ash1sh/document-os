# Document OS

**Document OS** is a local-first web application designed to manage business documents—including **Quotations, Invoices, Proposals, Estimates, Work Orders, Receipts, and Maintenance Contracts**.

Built with React, TypeScript, Vite, and Dexie.js (IndexedDB). Operates offline inside the browser.

---

## Features

- **Document Management**: Create, edit, and manage quotations, invoices, estimates, and proposals.
- **Offline Storage**: Client-side IndexedDB storage using Dexie.js.
- **Document Export**: PDF and Word (`.docx`) file export.
- **Payment Tracking**: Track payment statuses and outstanding balances.

---

## Development

```bash
# Install dependencies
npm install

# Start local server
npm run dev

# Build for production
npm run build
```
